# Перечень заинтересованных лиц (стейкхолдеров)

## Социальные сети/администраторы платформ
Основные пользователи системы. Им необходимо удобное средство для выявления и блокировки ботов, угрожающих экосистеме.

## Аналитики данных
Используют инструмент для анализа данных и исследования бот-активности.

# Перечень функциональных требований

## Веб-клиент (интерфейс для администратора платформы)

### Мониторинг активности
- Личный кабинет с дашбордом для отображения ключевых метрик:
  - Количество анализируемых аккаунтов.
  - Число выявленных ботов.
  - Графики активности и связей.
- История выполненных анализов и отчеты о результатах.

### Анализ пользователей
- Загрузка данных для анализа:
  - Подключение через API социальной сети.
  - Импорт данных в формате CSV или JSON.
- Вывод списка подозрительных аккаунтов:
  - Индекс подозрительности (вычисленный на основе аномалий).
  - Характеристики аккаунта: частота публикаций, шаблоны текстов, время активности.
- Возможность пометки аккаунтов для ручной проверки или немедленного блокирования.

### Выявление бот-сетей
- Построение графа связей между пользователями:
  - Анализ связей (например, перекрёстные лайки, комментарии).
  - Группировка подозрительных аккаунтов в кластеры.
- Возможность визуализации и фильтрации (например, только подозрительные группы).

### Генерация отчетов
- Автоматическая генерация PDF или Excel-отчетов с результатами анализа.
- Включение графиков, списка подозрительных аккаунтов и визуализации связей.
- Рассылка отчетов по электронной почте администраторам.

### Уведомления
- Уведомления в реальном времени:
  - Об обнаружении высокоопасных ботов.
  - О завершении процесса анализа.
- Настраиваемые параметры оповещений.

## Сервер

### Хранение данных
- Безопасное хранение загруженных данных и отчетов.
- Автоматическое удаление устаревших данных для экономии памяти.

### Механизм анализа
- Использование моделей машинного обучения:
  - Обучение моделей на основе исторических данных.
  - Обнаружение аномалий в поведенческих данных.
- Вычисление метрик для подозрительных аккаунтов:
  - Временные паттерны (ночная активность).
  - Однотипные действия (лайки, комментарии).

### API интеграция
- REST API для подключения к социальным платформам:
  - Сбор данных в реальном времени.
  - Передача результатов анализа (блокировка аккаунтов).

## Дополнительные функции

### Автоматизация действий
- Настройка сценариев автоматического удаления или пометки ботов.

### Обратная связь
- Инструмент для анализа эффективности алгоритмов.

# Перечень сделанных предположений

## Технические предположения
- Веб-клиент будет работать в браузерах Chrome, Firefox, Safari.
- Для анализа данных используется Python с библиотеками машинного обучения (например, Scikit-learn).

## Бизнес-предположения
- Система интегрируется с социальными сетями через их публичные API.
- Основные заказчики — крупные социальные сети.

# Перечень нефункциональных требований

## Производительность
- Время анализа 100 тыс. аккаунтов — не более 10 минут.

## Безопасность
- Данные анализируемых пользователей хранятся в зашифрованном виде.

## Масштабируемость
- Возможность обработки данных для 1 млн+ аккаунтов одновременно.

## Совместимость
- Поддержка работы в Docker-контейнерах.
