# Разработка программного решения для анализа и выявления бот-активности в социальных сетях

Система предоставляется как SaaS (Software as a Service) для администраций соцсетей или аналитических агентств.  
Веб-клиент реализован с использованием современных технологий (React.js для фронтенда и Django/FastAPI/Node.js для бэкенда).  
Веб-приложение доступно на любом устройстве с браузером и интернетом.

---

## Пользователи

- **Социальные сети/администраторы платформ:**  
  Основные пользователи программного решения. Им необходимо средство для выявления и блокировки ботов и бот-сетей, угрожающих экосистеме социальной сети.

- **Аналитики данных:**  
  Используют инструмент для исследования активности и поведения аккаунтов.

---

## Требования

### Веб-клиент для администратора платформы

#### Инструменты мониторинга
- Личный кабинет с дашбордом, где отображаются текущие метрики (количество анализируемых аккаунтов, выявленных ботов, активности).
- Уведомления о завершении анализа или обнаружении бот-сетей.

#### Анализ пользователей
- Возможность загрузки данных для анализа (API-интеграция или импорт CSV/JSON).
- Просмотр подозрительных аккаунтов с их характеристиками (график активности, индекс подозрительности).

#### Инструменты визуализации
- Интерактивный граф связей между пользователями, где можно выделить подозрительные группы.
- Вкладки с детализированными данными по каждому аккаунту.

#### Генерация отчетов
- Просмотр и скачивание отчетов в PDF или Excel.
- Экспорт данных для последующего анализа в других системах.

---

### Сервер

#### Хранение данных
- Обеспечение безопасного хранения собранной информации, включая отчеты и метаданные активности.
- Удаление устаревших данных через заданное время для оптимизации.

#### Анализ данных
- Обработка большого объема данных (в реальном времени или по расписанию).
- Поддержка моделей машинного обучения для классификации аккаунтов.

#### Интеграция
- REST API для подключения к социальным сетям.

---

Система предоставляет мощные инструменты для анализа активности пользователей, выявления аномалий и автоматической классификации подозрительных аккаунтов.
