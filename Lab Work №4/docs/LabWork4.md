# Документация по API

## Работа с пользователями

### 1. Создание нового пользователя
**Метод:** `POST`  
**Endpoint:** `/users`  

#### Описание:
Создает нового пользователя и возвращает его данные.

#### Заголовки:
- `Content-Type: application/json`

#### Тело запроса (JSON):
| Параметр   | Тип    | Обязательный | Описание                          |
|------------|--------|--------------|-----------------------------------|
| `username` | string | Да           | Имя пользователя                 |
| `email`    | string | Да           | Электронная почта пользователя   |
| `password` | string | Да           | Пароль пользователя             |

#### Пример тела запроса:
```json
{
  "username": "eugene",
  "email": "oneevgexa@gmail.com",
  "password": "password24"
}
```

#### Коды статуса ответа:
- `201 Created`: Пользователь успешно создан.
- `409 Conflict`: Пользователь с таким email уже существует.
- `422 Unprocessable Entity`: Некорректный запрос.

#### Формат ответа (JSON):
```json
{
  "user_id": 24,
  "username": "eugene",
  "email": "oneevgexa@gmail.com"
}
```

---

### 2. Получение данных о пользователе
**Метод:** `GET`  
**Endpoint:** `/users/{id}`  

#### Описание:
Получает информацию о пользователе по его ID.

#### Заголовки:
- `Authorization: Bearer {ваш_токен}`

#### Параметры запроса:
| Параметр | Тип    | Обязательный | Описание       |
|----------|--------|--------------|---------------|
| `id`     | int    | Да           | ID пользователя|

#### Пример запроса:
`/users/24`

#### Коды статуса ответа:
- `200 OK`: Успешный запрос.
- `401 Unauthorized`: Ошибка авторизации.
- `404 Not Found`: Пользователь не найден.

#### Формат ответа (JSON):
```json
{
  "user_id": 24,
  "username": "eugene",
  "email": "oneevgexa@gmail.com"
}
```

## Работа с жалобами

### 11. Создание жалобы
**Метод:** `POST`  
**Endpoint:** `/reports`  

#### Описание:
Создает новую жалобу на пользователя или публикацию.

#### Заголовки:
- `Content-Type: application/json`
- `Authorization: Bearer {ваш_токен}`

#### Тело запроса (JSON):
| Параметр           | Тип    | Обязательный | Описание                          |
|--------------------|--------|--------------|-----------------------------------|
| `reported_user_id` | int    | Нет          | ID пользователя, на которого подается жалоба |
| `reported_post_id` | int    | Нет          | ID публикации, на которую подается жалоба |
| `reason`           | string | Да           | Причина жалобы                    |
| `description`       | string | Нет          | Дополнительные сведения           |

#### Пример тела запроса:
```json
{
  "reported_user_id": 24,
  "reason": "Оскорбления в комментариях",
  "description": "Пользователь неоднократно оскорбляет других в обсуждениях."
}
```

#### Коды статуса ответа:
- `201 Created`: Жалоба успешно создана.
- `400 Bad Request`: Ошибка в запросе.
- `401 Unauthorized`: Ошибка авторизации.

#### Формат ответа (JSON):
```json
{
  "report_id": 456,
  "status": "pending",
  "created_at": "2024-02-26T12:00:00Z"
}
```

---

| `status` | string | Нет          | Статус жалобы (`pending`, `reviewed`, `rejected`) |

#### Пример запроса:
`/reports?status=pending`

#### Коды статуса ответа:
- `200 OK`: Успешный запрос.
- `401 Unauthorized`: Ошибка авторизации.

#### Формат ответа (JSON):
```json
[
  {
    "report_id": 456,

    "created_at": "2024-02-26T12:00:00Z"

  {
    "report_id": 789,

    "reason": "Спам",
    "status": "reviewed",
```
